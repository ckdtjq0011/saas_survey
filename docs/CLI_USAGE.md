## 실행 방법

### 기본 실행

```bash
python main.py
```

또는

```bash
python main.py run
```

### CLI 옵션

```bash
python main.py run [OPTIONS]
```

사용 가능한 옵션:

- `--data-dir, -d PATH`: 데이터 저장 디렉토리 지정 (기본값: data)
- `--debug`: 디버그 모드 활성화 (상세한 로그 출력)
- `--verbose, -v`: 자세한 출력 모드
- `--clear-session`: 저장된 세션을 삭제하고 시작 (자동 로그인 초기화)

### 기타 명령어

```bash
# 버전 정보 확인
python main.py version
```

## 시작하기

### 멀티테넌트 개념

이 플랫폼은 SaaS 멀티테넌트 아키텍처로 설계되었습니다:

- **테넌트(Tenant)**: 각 조직/기관 단위
- **사용자(User)**: 테넌트에 속한 사용자들
- **역할(Role)**: 사용자별 권한 수준

### 최초 사용 워크플로우

1. **테넌트 등록**: 조직 생성
2. **사용자 등록**: 첫 번째 사용자는 자동으로 TENANT_ADMIN 역할 부여
3. **로그인**: 인증 후 역할에 맞는 메뉴 표시
4. **기능 사용**: 권한에 따라 설문 생성, 응답 제출 등

## 역할 및 권한

### 역할 종류

| 역할 | 설명 | 주요 권한 |
|------|------|----------|
| **TENANT_ADMIN** | 테넌트 관리자 | 모든 기능 사용 가능 (사용자 관리, 범주 관리 포함) |
| **SURVEY_MANAGER** | 설문 관리자 | 설문 생성/수정/삭제, 결과 조회 |
| **RESPONDENT** | 응답자 | 설문 응답, 자신의 응답 수정/삭제 |

| 기능 | TENANT_ADMIN | SURVEY_MANAGER | RESPONDENT |

## 기능별 사용법

### 1. 테넌트 등록

새로운 조직/기관을 등록합니다.

```
선택: 1

테넌트 등록
----------
테넌트 이름: 서울대학교병원
테넌트 설명: 서울대학교병원 설문조사 시스템

[성공] 테넌트가 등록되었습니다 (ID: tenant_123)
```

### 2. 테넌트 목록 조회

등록된 모든 테넌트를 조회합니다.

```
선택: 2

테넌트 목록
----------

총 2개의 테넌트:

[1] 서울대학교병원
    ID: tenant_123
    설명: 서울대학교병원 설문조사 시스템
    사용자 수: 5명

[2] 강남세브란스병원
    ID: tenant_456
    설명: 강남세브란스병원 만족도 조사
    사용자 수: 3명
```

### 3. 사용자 등록

테넌트에 사용자를 등록합니다. 첫 번째 사용자는 자동으로 TENANT_ADMIN 역할이 부여됩니다.

```
선택: 3

사용자 등록
----------
사용자 이름: 홍길동
이메일: admin@hospital.com
비밀번호: ********
비밀번호 확인: ********

테넌트 ID: tenant_123
역할 (TENANT_ADMIN/SURVEY_MANAGER/RESPONDENT): TENANT_ADMIN

[성공] 사용자가 등록되었습니다
```

### 4. 로그인

등록된 이메일과 비밀번호로 로그인합니다.

```
선택: 4

로그인
------
이메일: admin@hospital.com
비밀번호: ********

[성공] 로그인 되었습니다
사용자: 홍길동 (admin@hospital.com)
역할: TENANT_ADMIN
```

로그인 후 역할에 맞는 메뉴가 표시됩니다.

### 5. 설문 생성

새로운 설문을 생성합니다. (TENANT_ADMIN, SURVEY_MANAGER만 가능)

```
설문 관리 > 1

설문 생성
--------
설문 제목: 2024년 병원 만족도 조사
설문 설명: 환자분들의 병원 이용 경험을 개선하기 위한 설문입니다

대범주 ID (선택사항):
소범주 ID (선택사항):

[성공] 설문이 생성되었습니다 (ID: survey_789)
```

### 6. 설문 조회

특정 설문의 상세 정보를 조회합니다.

```
설문 관리 > 2

설문 조회
--------
설문 ID: survey_789

제목: 2024년 병원 만족도 조사
설명: 환자분들의 병원 이용 경험을 개선하기 위한 설문입니다
생성일: 2025-11-15T10:30:00
상태: 활성

질문 목록 (총 5개):

[1] 전반적인 병원 서비스에 만족하십니까? (필수)
    ID: question_001
    유형: RATING (평점 1-5)

[2] 가장 만족스러웠던 부분은 무엇입니까?
    ID: question_002
    유형: MULTIPLE_CHOICE (객관식)
    선택지: 의료진 친절도, 대기 시간, 시설 청결도, 진료 결과

[3] 방문 날짜를 입력해주세요 (필수)
    ID: question_003
    유형: DATE (날짜)

[4] 병원을 추천하시겠습니까?
    ID: question_004
    유형: YES_NO (예/아니오)

[5] 개선이 필요한 사항을 자유롭게 작성해주세요
    ID: question_005
    유형: TEXT (텍스트)
```

### 7. 설문 수정

기존 설문의 정보를 수정합니다. (TENANT_ADMIN, SURVEY_MANAGER만 가능)

```
설문 관리 > 3

설문 수정
--------
설문 ID: survey_789

새로운 제목 (현재: 2024년 병원 만족도 조사):

```

```
설문 관리 > 4

설문 삭제
--------
설문 ID: survey_789

정말 삭제하시겠습니까? (y/n): y

[성공] 설문이 삭제되었습니다
```

### 9. 질문 추가

설문에 새로운 질문을 추가합니다. (TENANT_ADMIN, SURVEY_MANAGER만 가능)

```
설문 관리 > 5

질문 추가
--------
설문 ID: survey_789
질문 내용: 병원 시설의 청결도는 어떠했습니까?

질문 유형:
1. TEXT (텍스트)
2. RATING (평점 1-5)
3. MULTIPLE_CHOICE (객관식)
4. DATE (날짜)
5. NUMBER (숫자)
6. EMAIL (이메일)
7. YES_NO (예/아니오)
8. SCALE_10 (10점 척도)
9. MULTI_SELECT (다중 선택)

유형 선택: 8

필수 질문으로 설정하시겠습니까? (y/n): y

[성공] 질문이 추가되었습니다 (ID: question_006)
```

#### 객관식 질문 추가 예시

```
질문 유형: 3 (MULTIPLE_CHOICE)
선택지 (|로 구분): 매우 만족|만족|보통|불만족|매우 불만족

[성공] 질문이 추가되었습니다
```

#### 다중 선택 질문 추가 예시

```
질문 유형: 9 (MULTI_SELECT)
선택지 (|로 구분): 의료진 친절도|진료 대기시간|시설 청결도|주차 편의성|예약 시스템

[성공] 질문이 추가되었습니다
```

## 질문 유형

플랫폼에서 지원하는 9가지 질문 유형:

### 1. TEXT (텍스트)

자유 형식의 텍스트 입력

```
질문: 개선이 필요한 사항을 자유롭게 작성해주세요
답변: 대기 시간이 조금 길었습니다
```

### 2. RATING (평점 1-5)

1-5 사이의 평점 입력

```
질문: 전반적인 병원 서비스에 만족하십니까?
답변: 5
(1: 매우 불만족, 5: 매우 만족)
```

### 3. MULTIPLE_CHOICE (객관식)

여러 선택지 중 하나 선택

```
질문: 가장 만족스러웠던 부분은 무엇입니까?
선택지: 의료진 친절도, 대기 시간, 시설 청결도, 진료 결과
답변: 의료진 친절도
```

### 4. DATE (날짜)

날짜 입력 (YYYY-MM-DD 형식)

```
질문: 방문 날짜를 입력해주세요
답변: 2025-11-15
```

### 5. NUMBER (숫자)

숫자 입력

```
질문: 병원 방문 횟수를 입력해주세요
답변: 3
```

### 6. EMAIL (이메일)

이메일 주소 입력 (형식 검증)

```
질문: 연락 가능한 이메일을 입력해주세요
답변: patient@example.com
```

### 7. YES_NO (예/아니오)

예 또는 아니오 선택

```
질문: 병원을 추천하시겠습니까?
답변: y (또는 n)
```

### 8. SCALE_10 (10점 척도)

1-10 사이의 점수 입력

```
질문: 병원 시설의 청결도를 평가해주세요
답변: 9
(1: 매우 불만족, 10: 매우 만족)
```

### 9. MULTI_SELECT (다중 선택)

여러 선택지 중 복수 선택 (|로 구분)

```
질문: 개선이 필요한 항목을 모두 선택해주세요
선택지: 의료진 친절도, 대기 시간, 시설 청결도, 주차 편의성, 예약 시스템
답변: 대기 시간|주차 편의성
```

## 데이터 저장

### SQLite (기본값)

기본적으로 SQLite 데이터베이스를 사용합니다:

- 데이터베이스 파일: `data/survey.db`
- ORM: SQLAlchemy
- 마이그레이션: Alembic

#### 주요 테이블

- `tenants`: 테넌트 정보
- `users`: 사용자 정보
- `major_categories`: 대범주
- `minor_categories`: 소범주
- `surveys`: 설문 기본 정보
- `questions`: 질문 정보
- `responses`: 응답 정보
- `survey_sessions`: 설문 세션 추적

### CSV (레거시)

CSV 파일 저장 방식도 지원합니다:

`config.py`에서 `storage_type = "csv"`로 설정

- `data/surveys.csv`: 설문 기본 정보
- `data/questions.csv`: 질문 정보
- `data/responses.csv`: 응답 정보

## 고급 기능

### 세션 관리 및 자동 로그인

로그인 상태는 세션 파일에 저장되어 다음 실행 시 자동으로 로그인됩니다.

```bash
# 세션 초기화하고 시작
python main.py run --clear-session
```

세션 파일 위치: `data/.session`

### 디버그 모드

상세한 로그를 출력하여 문제를 진단할 수 있습니다.

```bash
python main.py run --debug
```

디버그 모드에서는:
- 상세한 SQL 쿼리 로그
- 함수 호출 스택 트레이스
- 상세한 예외 정보

### 설문 세션 추적

응답 제출 시 소요 시간이 자동으로 측정됩니다:

- 시작 시간 기록
- 종료 시간 기록
- 소요 시간 계산 및 표시

### 응답 수정 이력

응답 수정 시 이력이 기록됩니다:

- 수정 전 값
- 수정 후 값
- 수정 시간
- 수정자

## 주요 특징

1. **역할 기반 접근 제어**: 사용자 역할에 따라 동적 메뉴 구성
2. **멀티테넌트 지원**: 여러 조직이 독립적으로 사용 가능
3. **Rich UI**: 테이블, 색상, 진행률 표시 등 풍부한 UI
4. **입력 검증**: 이메일, 날짜, 숫자 등 형식 자동 검증
5. **실시간 진행률**: 응답 제출 시 진행 상황 표시
6. **필수/선택 질문 구분**: 질문별 필수 여부 설정 가능
7. **CSV 내보내기**: 결과를 CSV로 내보내기 가능
8. **자동 로그인**: 세션 기반 자동 로그인
9. **세션 추적**: 설문 응답 소요 시간 측정

## 오류 처리

프로그램 실행 중 오류가 발생하면 다음과 같이 표시됩니다:

```
[오류] 설문 조회 중 오류가 발생했습니다
```

디버그 모드에서는 상세한 스택 트레이스가 출력됩니다.

로그 파일 위치: `logs/app.log`

## 종료 방법

- 메뉴에서 `0` 선택
- `Ctrl+C` 키 입력 (안전하게 종료됨)

## 팁

1. **설문 ID 확인**: 설문 목록 조회 또는 설문 조회 기능 사용
2. **객관식 선택지**: `|` 문자로 구분하여 입력
3. **다중 선택 답변**: `|` 문자로 구분하여 여러 개 입력
4. **날짜 형식**: YYYY-MM-DD 형식 사용 (예: 2025-11-15)
5. **이메일 검증**: 올바른 이메일 형식만 허용
6. **세션 초기화**: 로그인 문제 발생 시 `--clear-session` 옵션 사용
7. **빠른 개발**: `--debug` 모드로 상세한 로그 확인
8. **공백 처리**: 모든 입력은 자동으로 앞뒤 공백 제거
